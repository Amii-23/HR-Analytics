HR Analytics Dashboard
📊 Project Overview

This project analyzes 311 employee records to identify workforce trends, employee attrition, salary patterns, employee satisfaction, and recruitment insights. The analysis was performed using Python, SQL, and Power BI.

The dashboard provides an interactive view of employee attrition across different departments, gender, salary bands, age groups, employment status, and recruitment sources.

🛠️ Tools & Technologies
Python (Pandas) – Data cleaning and transformation
MySQL – Data analysis and SQL queries
Power BI – Interactive dashboard and data visualization
📌 Key Metrics
👥 Total Employees: 311
🟢 Active Employees: 207
🔴 Terminated Employees: 104
📉 Attrition Rate: 33.44%
💰 Average Salary: 69.02K
⭐ Average Employee Satisfaction: 3.89
📈 Dashboard Analysis

The dashboard analyzes employee attrition based on:

Department
Gender
Salary Band
Age Group
Employment Status
Recruitment Source

It also includes interactive filters for employment status, salary band, and department.

🔍 Key Insights
The overall employee attrition rate is 33.44%, with 104 employees terminated.
Attrition patterns vary across different departments and salary bands.
Gender-based analysis shows a nearly balanced distribution of attrition.
Employees in different age groups demonstrate varying attrition rates.
Recruitment source analysis helps identify which hiring channels contribute to employee turnover.
Employee salary, satisfaction, and employment status were analyzed to understand workforce trends.
🧹 Data Cleaning

The dataset was cleaned using Python, including:

Handling missing values in DateofTermination
Keeping missing termination dates for active employees
Converting inconsistent date formats into proper datetime format
Preparing the cleaned dataset for SQL analysis and Power BI visualization
